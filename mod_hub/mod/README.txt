mod/ 目录 - GMod 附加组件存放处
================================

把任意 GMod 附加组件（.gma 文件）放进本目录。

- 启动游戏时，模组自动扫描本目录：解析 + CRC 校验 + 解包到
  ../mod_unpacked/，并把解包内容挂载进游戏（模型/材质/地图立即可用）；
- 游戏运行中往本目录新丢 .gma 后，在控制台执行:
    modhub_scan
  即可即时挂载，无需重启；
- 幂等：文件未修改时二次启动直接命中缓存，跳过解包。

注意：
- 运行时自动解析需要已编译引擎钩子（src/ModHubEngine，见仓库
  README-engine.txt）；纯内容层部署（如安卓 hl2/custom 方式）不会
  自动解包，此时请把 .gma 解包后的 models/ materials/ 手动放到
  模组对应目录。
